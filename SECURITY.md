# Security and privacy

This repository contains archived instructions and local processing scripts. It does not provide the original Grok host, credentials, or a maintained authentication service.

Do not post a credential, token, session, private URL, or personal data in a public issue or pull request. If you discover an exposure, use GitHub's private vulnerability reporting option when it is available. Otherwise open a minimal issue requesting a private reporting channel, without including the sensitive material or its value.

If a credential is ever exposed, its owner should revoke or rotate it. Removing it from the latest commit does not remove downloaded copies or earlier Git objects.

Read scripts before running them, work with copies of assets, and check archived platform instructions against the current host. Validation of this archive does not establish that the original Grok services or example application security still behave as documented.
