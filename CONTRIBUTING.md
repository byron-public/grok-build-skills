# Contributing

Keep changes focused on the archive's accuracy, usability, and provenance.

- Link public evidence for source or licensing claims. Do not describe material as confidential, leaked, exclusive, or official without evidence.
- Preserve existing third-party attribution and license notices.
- Keep archived source changes explicit. Record intentional updates in the manifest and provenance notes instead of silently rewriting upstream files.
- Exclude credentials, private project notes, live configuration, runtime state, generated assets, and personal filesystem paths.
- Run the checks in [verification](docs/verification.md) before submitting a change.

Issues and pull requests are public. Use synthetic examples and report sensitive issues through the process in [SECURITY.md](SECURITY.md).
